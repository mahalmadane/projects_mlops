mlstrat
Ce que ça fait Installer Créer un projet Configs Outils Aide

Démarre un projet de machine learning en une commande.

mlstrat crée la structure complète de ton projet (dossiers, notebooks, configs commentées) et te donne des outils prêts à l'emploi pour explorer, nettoyer et modéliser tes données.

Commencer

Ce que fait mlstrat

Deux choses : préparer ton projet, puis t'aider à travailler dedans.

1

Structure de projet

mlstrat new crée tous les dossiers d'un projet ML propre : données, notebooks, code, tests, rapports.

2

Configs commentées

Chaque fichier de configs/ contient un exemple concret et le code Python pour s'en servir, en commentaire.

3

Outils d'analyse

Exploration des données, valeurs manquantes, outliers et entraînement de modèles scikit-learn en quelques lignes.

Installer

Il faut Python 3.10 ou plus récent, et git.

pip3 install "git+https://github.com/mahalmadane/projects_mlops.git#subdirectory=mlstrat"

Pour vérifier que tout est bien installé :

mlstrat --version
Mettre à jour vers la dernière version : ajoute -U à la commande d'installation. 
pip3 install -U "git+https://github.com/mahalmadane/projects_mlops.git#subdirectory=mlstrat"

Créer un projet

De zéro à un projet prêt à coder, en 5 étapes.

  1. Créer la structure

    mlstrat new mon_projet
cd mon_projet

  2. Créer l'environnement virtuel

    Un environnement par projet, pour ne pas mélanger les versions.

    python3 -m venv .venv
source .venv/bin/activate        # Windows : .venv\Scripts\activate

  3. Choisir ses outils

    Ouvre requirements.txt et mets un # devant ce dont tu n'as pas besoin (par exemple zenml ou mlflow). Rien n'est installé sans ton accord.

  4. Installer les dépendances

    pip install -r requirements.txt
pip install -e .                 # rend src/ importable, n'installe rien d'autre

  5. Ajouter tes données et commencer

    Mets ton fichier dans data/raw/, puis ouvre le premier notebook.

    jupyter notebook notebooks/01_exploration.ipynb

Ce qui est créé

mon_projet/
├── data/
│   ├── raw/            # données d'origine, jamais modifiées
│   ├── interim/        # données en cours de transformation
│   └── processed/      # données prêtes pour l'entraînement
├── notebooks/          # exploration, prétraitement, entraînement
├── src/
│   ├── data/           # chargement et nettoyage
│   ├── features/       # création de variables
│   ├── models/         # entraînement, évaluation, prédiction
│   ├── utils/
│   └── pipelines/      # pipeline et ses étapes
├── configs/            # config.yaml, model_params.yaml, pipeline_config.yaml
├── reports/            # figures et métriques
├── scripts/            # lancer, entraîner, déployer
├── tests/
├── requirements.txt    # dépendances à installer
├── pyproject.toml
└── README.md           # guide d'installation du projet

Si un fichier existe déjà, il n'est jamais écrasé : tu peux relancer mlstrat new sur un projet existant pour ajouter ce qui manque.

Les fichiers de configuration

Tout est en commentaire. Décommente (enlève le # ) et adapte ce dont tu as besoin.

FichierExemple fourniUtilisation montrée
config.yamlChemins des données, colonne cible, découpage train/test, valeurs manquantes, outliers, MLflowCharger, nettoyer, enregistrer et découper les données
model_params.yamlPlusieurs modèles et leurs hyperparamètres, métrique de choixEntraîner chaque modèle et garder le meilleur
pipeline_config.yamlRun ZenML : nom, cache, paramètres par étapeLancer un pipeline ZenML avec cette config

Extrait de configs/config.yaml :

# preprocessing:
#   missing_values:                         # stratégie par colonne
#     age: median                           # mean | median | mode | min | max
#     city: Unknown                         # ou une valeur constante
#   outliers:
#     factor: 1.5                           # bornes Q1 - 1.5*IQR / Q3 + 1.5*IQR
#     exclude: [target]                     # colonnes à ne pas toucher

Utiliser les outils

Dans un notebook ou un script, une fois les dépendances installées.

import pandas as pd
from mlstrat import DataOverview, MissingValueImputer, OutlierClipper, ModelTrainer
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("data/raw/mes_donnees.csv")

# 1. Voir l'état des données : type, valeurs manquantes, valeurs uniques
DataOverview().report(df)

# 2. Nettoyer (le DataFrame d'origine n'est pas modifié)
df = MissingValueImputer(df).impute("age", "median").impute_all().get_df()
df = OutlierClipper(df).clip_all(exclude=["target"]).get_df()

# 3. Entraîner et évaluer

Problèmes fréquents

Les solutions aux blocages les plus courants.

« command not found: mlstrat »

Le dossier où pip installe les commandes n'est pas dans ton PATH. Utilise cette forme, qui marche toujours :

python3 -m mlstrat.cli new mon_projet
Mes fichiers de config sont presque vides

Tu as une ancienne version. Mets à jour, supprime les anciens fichiers de config, puis relance (seuls les fichiers manquants sont recréés) :

pip3 install -U "git+https://github.com/mahalmadane/projects_mlops.git#subdirectory=mlstrat"
rm mon_projet/configs/*.yaml
mlstrat new mon_projet
L'installation de requirements.txt est longue

ZenML et MLflow sont gros. Si tu ne t'en sers pas, commente leurs lignes dans requirements.txt avant d'installer.
